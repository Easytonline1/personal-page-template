صفحتي الشخصية
==============

صفحة شخصية لعرض معلوماتك وأعمالك، وهي قالب تنسخه إلى حسابك على GitHub ثم تضع بياناتك مكان بيانات القالب.

محتوى المشروع
-------------

- `public`: ما يصل إلى الزائر وهو الذي ينشر على Vercel. فيه `index.html` و`style.css` و`script.js` و`projects.json` و`photo.jpg`.
- `contact`: مثال للقراءة فقط عن كيف يستقبل الخادم رسالة التواصل. لا ينشر، ولا يستقبل رسائل ولا يرسل بريدا.
- `.env.example`: أسماء الإعدادات التي يحتاجها المشروع بلا قيم.
- `.gitignore`: ما لا يرفعه Git إلى المستودع.

طريقة الاستعمال
---------------

1. انسخ القالب إلى حسابك بزر Use this template.
2. افتح الملفات في المحرر وغيّر الاسم والصورة والأعمال إلى بياناتك.
3. انشر مجلد `public` على Vercel.
